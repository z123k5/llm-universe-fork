API 文档:
目标: http://127.0.0.1:8082

1. 查询站名，由地名模糊查找站名，或者一次查询所有站名
(GET) http://127.0.0.1:8082/api/v1/queryStation
** Arguments
station | string | 可选参数

** Returns (JSON Array):
stations | Array[station]
** Each element include in `stations` as:
stationName | string (站名)
stationCode | string (英文代码，三个字母)


2. 查询直达，从用户问题中获取始发地from、目的地to、预期出发时间（可选），发起查询直达航班请求。
(GET) http://127.0.0.1:8082/api/v1/queryFlight
** Arguments:
date | Date(日期格式"2020-10-1") | 可选参数
from | string (始发地，模糊查找) | 可选参数
to | string (目的地，模糊查找) | 可选参数

** Returns (JSON Array):
flights | Array[flight] (航班对象数组)
** Each element include in `flights` as:
flightId | number (航班编号，请务必记住航班对应的该编号，用于后面提交订单时使用)
flightCode | string (航班编号，2位公司英文编号+4位数字序列号)
flightName | string (班次名称)
supportStudent | Boolean (是否支持学生票)
price | number (价格)
from | string (始发地，模糊查找)
to | string (目的地，模糊查找)
info | string (描述)
num | number (剩余票数)
avatar | string (图像路径)


3. 制定行程计划：从历史对话中得到始发地from和目的地to，还有预期出发时间date，然后发起查询航线请求。
(GET) http://127.0.0.1:8082/api/v1/plan
** Arguments:
date | Date(日期格式"2020-10-1") | 可选参数
from | string | 可选参数（from和to不能只填一个，不然只根据日期查询）
to | string | 可选参数（from和to不能只填一个，不然只根据日期查询）

** Returns (JSON Array):
flights | Array[flight] (航班对象数组)
** Each element include in `flights` are sequential:
flightId | number (航班编号，请务必记住航班对应的该编号，用于后面提交订单时使用)
flightCode | string (航班编号，2位公司英文编号+4位数字序列号)
price | number (价格)
from | string (始发地，模糊查找)
to | string (目的地，模糊查找)
num | number (剩余票数)
avatar | string (图像路径)



4. 发起订单：从对话历史中筛选出用户预期的flightId，组合成一个数组，然后与userId一起发起订票请求。
(POST) http://127.0.0.1:8082/api/v1/appendOrder
** Arguments:
userId | number (用户编号) | 必填
flightsId | Array[flightId] (航班编号数组) | 必填

** Returns (JSON object):
status | "true" 如果成功 "false" 如果失败
msg | string (订单结果描述)
price | number (订单价格)
orderId | string (订单编号)
imgUrl | string (支付付款码地址)
msg | string (订单描述)
